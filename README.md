📖 About
My Code Verse is my personal collection of code written while learning, practising and building. It covers almost every language I have worked with, from basic programs and DSA problems to complete projects.

The goal is simple: one place to learn by doing, revisit concepts quickly, and show how the same idea looks in different languages.
