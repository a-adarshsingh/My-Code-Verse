# 🧠 AI Paragraph Generator & File Summarizer (Python + Llama 3.2)

## Setup
1. Install Ollama: https://ollama.com  ->  `ollama pull llama3.2`
2. `python -m pip install -r requirements.txt`
3. `python -m streamlit run app.py`  (the Run button also works)

## Features
- Topic -> paragraph of YOUR word count (50-3000), shown live while writing
- Then: short summary, keywords, hard words with Hindi + English meaning
- Upload PDF/DOCX/TXT -> summary + key points + keywords + meanings
- Themes, username, per-user history in the sidebar
- Languages: English / Hindi / Hinglish
